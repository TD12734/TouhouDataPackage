This repository is the development repository for Touhou Data Package.

この文書は日本語(上)と英語(下)の2言語に対応しています。

This document is available in two languages: Japanese (top) and English (bottom).

## 開発環境(Development environment)
UnityとVisual Studio Code(文書作成)を使用します。

We use Unity and Visual Studio Code (documentation).

### Unity
Unity6000.0.15f1

### Visual Studio Code
[Markdown PDF](https://marketplace.visualstudio.com/items?itemName=yzane.markdown-pdf) を使用してDevDocumentsディレクトリにあるマークダウンをpdfとして書き出し、Documentsディレクトリに移動させます。

Use [Markdown PDF](https://marketplace.visualstudio.com/items?itemName=yzane.markdown-pdf) to export the markdown in the DevDocuments directory as a pdf and move it to the Documents directory.
